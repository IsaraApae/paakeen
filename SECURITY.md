# Reporting a security problem

ป้าคีน holds people's income and expense records. A way to read or change someone else's entries, a way around the signed app link or the LINE webhook's signature check, or anything else that puts that data at risk is worth a private report.

**How to report it:** open [Report a vulnerability](https://github.com/IsaraApae/paakeen/security/advisories/new) (the repository's Security tab). The report is private. Please don't open a public issue for it.

It helps to say what you did, what happened, and what you expected to happen instead.

Only the latest version on `main` is looked after. This is a personal project, so a reply may take a few days.
